# Desafio Criativo: Planejando Automações com N8N

## Passo 1: Defina a automação desejada

Quero criar uma automação no N8N para receber e organizar solicitações de usuários automaticamente.

**Público ou responsável:**  
Equipe responsável pelo atendimento e acompanhamento das solicitações.

**Resultado esperado:**  
Receber a solicitação, organizar as informações, identificar a prioridade e enviar uma notificação para o responsável pelo atendimento.

## Passo 2: Adicione contexto e regras

**Ferramentas envolvidas:**  
N8N, formulário de entrada, Google Sheets e Gmail.

**Fluxo desejado:**

1. Receber uma nova solicitação por meio de um formulário.
2. Verificar se os dados obrigatórios foram preenchidos.
3. Registrar as informações em uma planilha.
4. Identificar a prioridade da solicitação.
5. Enviar um e-mail para o responsável com os dados da solicitação.
6. Manter o registro atualizado na planilha.

**Regras importantes:**  
Não processar solicitações que estejam sem informações obrigatórias. Caso algum dado esteja faltando, a automação deve informar que a solicitação precisa ser corrigida antes de continuar.

## Prompt final

Quero criar uma automação no N8N para receber e organizar solicitações de usuários automaticamente.

A automação será utilizada pela equipe responsável pelo atendimento e acompanhamento das solicitações.

O objetivo é receber uma solicitação por formulário, validar os dados, registrar as informações em uma planilha, identificar a prioridade e enviar uma notificação para o responsável pelo atendimento.

As ferramentas envolvidas serão N8N, um formulário de entrada, Google Sheets e Gmail.

O fluxo deve seguir estas etapas:

1. Receber uma nova solicitação por meio do formulário.
2. Verificar se todos os dados obrigatórios foram preenchidos.
3. Registrar os dados válidos no Google Sheets.
4. Identificar a prioridade da solicitação.
5. Enviar um e-mail ao responsável contendo as informações da solicitação.
6. Manter o registro atualizado.

Como regra, solicitações com informações obrigatórias faltantes não devem continuar no fluxo. Nesses casos, a automação deve informar que os dados precisam ser corrigidos antes do processamento.

Crie esse fluxo no N8N de forma organizada, utilizando boas práticas e deixando cada etapa clara para facilitar a manutenção e futuras alterações.
